
# Sistema Automatizado de Recaudo y Monitoreo para el Transporte Urbano de San Juan de Pasto

## Descripción del Proyecto

Este proyecto tiene como objetivo diseñar un sistema de software orientado a la automatización del sistema estratégico de transporte urbano en la ciudad de San Juan de Pasto.

La propuesta integra un sistema de recaudo electrónico mediante tarjetas inteligentes y un módulo de monitoreo de flota basado en tecnologías de geolocalización en tiempo real.

El sistema busca optimizar la gestión operativa del transporte público, mejorar la seguridad, reducir los tiempos de abordaje y fortalecer la experiencia de los usuarios.

## Funcionalidades del Prototipo

### Sistema de Tarjeta Inteligente
- Registro de tarjetas
- Inicio de sesión mediante cédula y PIN
- Recarga de saldo
- Pago de pasajes
- Gestión de saldo disponible

### Sistema de Monitoreo
- Monitoreo de rutas
- Simulación GPS
- Visualización de paradas
- Ubicación en tiempo real

### Sistema de Control de Puertas
- Apertura de puertas solo en paradas autorizadas
- Simulación de movimiento del vehículo
- Validación automática de seguridad

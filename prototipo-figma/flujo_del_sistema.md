# Flujo General del Sistema

1. El usuario accede al sistema de transporte.
2. El usuario crea una tarjeta inteligente.
3. El sistema almacena la información del usuario.
4. El usuario inicia sesión mediante cédula y PIN.
5. El usuario puede:
   - Recargar saldo
   - Pagar pasajes
   - Consultar información
6. El sistema valida las transacciones.
7. El sistema monitorea la ubicación del vehículo.
8. El sistema controla las puertas automáticamente en paradas autorizadas.

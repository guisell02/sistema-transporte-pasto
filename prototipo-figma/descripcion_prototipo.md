# Descripción del Prototipo

El prototipo interactivo fue diseñado en Figma con el objetivo de representar el funcionamiento del sistema automatizado de recaudo y monitoreo para el transporte urbano de San Juan de Pasto.

El diseño permite simular la experiencia del usuario dentro del sistema, incluyendo procesos de registro, autenticación, recarga de saldo, pago de pasajes y monitoreo del vehículo en tiempo real.

---

# Módulos Diseñados

## 1. Sistema de Tarjeta Inteligente
Permite:
- Crear tarjeta de transporte
- Registrar usuarios
- Validar identidad mediante cédula y PIN
- Gestionar saldo disponible
- Simular pagos electrónicos

## 2. Sistema de Recarga
Permite:
- Seleccionar montos de recarga
- Simular pagos electrónicos
- Actualizar saldo automáticamente

## 3. Sistema de Monitoreo
Permite:
- Visualizar rutas urbanas
- Monitorear ubicación del bus
- Consultar paradas autorizadas
- Simular geolocalización GPS

## 4. Sistema de Control de Puertas
Permite:
- Abrir puertas únicamente en paradas oficiales
- Validar estado del vehículo
- Simular operación segura del transporte

---

# Objetivo del Prototipo

Representar visualmente el funcionamiento del sistema antes del desarrollo funcional del frontend y backend.
